Vice Bay is a 2D top-down open-world crime game set on a 3200×2400 map: walk the streets or steal a car and drive through traffic and pedestrians, rack up a wanted level and outrun pursuing police cars, and complete 3 missions. It ships with a HUD and minimap, a start screen with save support, and synthesized sound effects — no build step, just open and play.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in your browser.
